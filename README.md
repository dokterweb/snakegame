# Snake Game Python

Game Snake sederhana yang dibuat menggunakan Python dan Pygame.

Project ini dikembangkan sebagai media pembelajaran pemrograman game untuk pemula.

## Fitur

- Main Menu
- Play Game
- Instructions
- Snake movement
- Food generation
- Score system
- Collision detection
- Game Over screen
- Restart game
- Sound effects
- Grid background
- Snake and apple graphics

## Teknologi

- Python
- Pygame

## Instalasi

1. Clone repository:

   ```bash
   git clone https://github.com/dokterweb/snakegame.git
   ```

2. Masuk ke folder project:

   ```bash
   cd snakegame
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Jalankan game:

   ```bash
   python main.py
   ```

## Kontrol

| Tombol      | Fungsi                 |
| ----------- | ---------------------- |
| Arrow Up    | Bergerak ke atas       |
| Arrow Down  | Bergerak ke bawah      |
| Arrow Left  | Bergerak ke kiri       |
| Arrow Right | Bergerak ke kanan      |
| R           | Restart saat Game Over |
| M           | Kembali ke menu        |
